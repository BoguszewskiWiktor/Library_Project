# Library Management System

A console application for managing a library, written in plain Java as a learning project.

## Features (planned)

- Add and search books
- Register library members
- Borrow and return books

## Tech stack

- Java 21
- Maven
- No frameworks (plain Java)

## Status

Work in progress. Data is currently stored in memory only.

## Getting started

1. Clone the repository.
2. Open the project in IntelliJ IDEA (JDK 21).
3. Run the `Main` class (`com.library.Main`).
